# FirewallDNS

Firewall DNS local para Android, creado por **Candido y Elizabeth**.

La aplicación filtra consultas DNS mediante una VPN local y permite administrar listas de bloqueo, reglas manuales y exclusiones por aplicación.

## Mejoras incluidas
- Tema Material 3 moderno con soporte dark mode.
- Estado visual del firewall en la pantalla principal.
- Tarjetas de resumen para bloqueados, permitidos y reglas.
- Credito de autor visible en la aplicación y en la documentación.
